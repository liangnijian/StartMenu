# 开始菜单 (StartMenu)


因为用不习惯 Windows 11 的开始菜单，所以让 deepseek 仿照 Windows 10 的开始菜单写一个程序

![主界面](docs/main.png)
---



## ✨ 特性

### 界面与交互
- **暗色主题自绘 UI**：标题栏、列表、磁贴、滚动条、右键菜单、对话框全部自绘，风格统一。
- **自定义无边框标题栏**：支持拖动、双击最大化、最小化 / 最大化 / 还原 / 关闭按钮。
- **左侧字母索引列表**
  - 按名称首字母自动分组、排序。
  - 支持中文拼音首字母映射（`A-Z` 共 23 个有效字母）。
  - 点击字母快速跳转到对应分组。
- **右侧磁贴分组**
  - 每组最多 4 列 × 6 行，可横向排列多个分组。
  - 分组标题支持**单击重命名**、**拖动调整顺序**。
  - 磁贴支持拖动到任意位置：同一组内换位、跨组移动、拖到空白处**新建分组**。
  - 拖动时组高度自动扩展、实时预览插入位置（竖线 / 空格框）。
- **自定义滚动条**：列表与磁贴区各自独立滚动，支持滑块拖动和点击轨道翻页。

### 功能
- **拖放添加**：从资源管理器把文件 / 快捷方式拖入窗口即自动添加为磁贴，支持拖入过程中实时高亮插入位置（OLE `IDropTarget`）。
- **快捷方式解析**：自动读取 `.lnk` 的目标路径、启动参数、工作目录。
- **右键菜单**：重命名、打开文件位置、移除快捷方式。
- **文件缺失检测**
  - 启动时与启动项前都会检查路径是否存在。
  - 缺失项列表与磁贴背景变**深红色**，并弹出提示对话框可一键移除。
- **可移植配置**
  - 配置文件保存为 `程序名.cfg`，与程序同目录。
  - 路径自动替换为 `%ProgramFiles%` / `%APPDATA%` / `%SystemRoot%` 等环境变量，便于整体迁移。
  - 程序所在目录内的文件保存为相对路径。

### 兼容性与适配
- **DPI 自适应**（多级回退，兼容 Win7 及以上）
  - Per-Monitor V2 → Per-Monitor → System DPI Aware。
  - 所有尺寸按 96 DPI 设计，运行时通过 `S()` 按当前 DPI 缩放。
  - 支持 `WM_DPICHANGED`，跨屏拖动自动重排。
- **分层窗口**：`WS_EX_LAYERED` 半透明背景（238 / 255 不透明度）。

## 🚀 使用

### 首次运行
- 程序会在**自身所在目录**下查找 / 生成 `程序名.cfg`（例如 `开始菜单.cfg`）。
- 同目录下放置 `logo.ico` 可用自定义标题栏和任务栏图标。

### 添加项目
- **拖放**：从资源管理器把文件或快捷方式直接拖到窗口中。
  - 拖到某个分组的磁贴区 → 插入到该位置。
  - 拖到窗口空白处 → 自动**新建分组**。
- **配置文件**：手动编辑 `.cfg` 文件（见下文格式）。

### 管理项目
| 操作 | 方式 |
|------|------|
| 启动项 | 单击磁贴 / 列表项 |
| 重命名 | 磁贴或列表项右键 → 重命名 |
| 打开文件位置 | 右键 → 打开文件位置 |
| 移除 | 右键 → 移除快捷方式 |
| 分组重命名 | 单击分组标题 |
| 分组重排 | 按住分组标题拖动 |
| 磁贴移动 | 按住磁贴拖动到目标位置 |
| 新建分组 | 把磁贴拖到窗口空白处 |
| 快速跳转 | 点击左侧字母索引 |

### 快捷操作
- `Esc` — 关闭对话框 / 取消编辑
- `Enter` — 确认对话框 / 提交编辑
- 双击标题栏 — 最大化 / 还原

## 📄 配置文件格式

配置文件使用 **UTF-16LE + BOM** 编码，保存于程序同目录，采用自定义 `.cfg` 格式：

```ini
[Window]
Width=982
Height=680
X=100
Y=100

[grouping]
number=1
name=游戏
1|赛博朋克2077|C:\Games\Cyberpunk 2077\bin\x64\Cyberpunk2077.exe|
2|我的世界|%APPDATA%\.minecraft\launcher.exe|--workDir "."

[grouping]
number=2
name=办公工具
1|记事本|%SystemRoot%\notepad.exe|
2|计算器|%SystemRoot%\system32\calc.exe|
```


### 字段说明

| 字段 | 说明 |
|------|------|
| `[Window]` | 窗口几何信息，宽高按 96 DPI 逻辑单位保存，跨 DPI 迁移时观感一致 |
| `Width` / `Height` | 窗口宽高（逻辑单位，96 DPI） |
| `X` / `Y` | 窗口左上角坐标（物理像素） |
| `[grouping]` | 一个磁贴分组 |
| `number` | 分组序号（1 起始） |
| `name` | 分组名，可为空字符串 |
| `序号\|名称\|路径\|参数` | 磁贴项。序号为位置（1 起始），支持跳跃以留空位；路径支持 `%变量%` 与相对路径；参数可为空 |

> 注：`|` 是分隔符，程序保存时会自动把名称 / 参数中的 `|` 替换为空格，避免解析冲突。

## ⚠️ 注意事项

- 程序依赖 **OLE 初始化**，`OleInitialize` 失败会导致拖放功能不可用。
- 配置文件使用 **UTF-16LE** 保存；用文本编辑器编辑时请确保保存为同编码，否则可能出现乱码或解析失败（`ReadAllText` 也支持 ANSI 与 UTF-8 BOM 读取）。
- 程序不修改系统开始菜单，**纯独立启动器**，不注入、不写注册表。
- 分层窗口在部分远程桌面 / 老显卡驱动下可能不透明显示，属系统限制。
